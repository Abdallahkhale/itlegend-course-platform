# Competition submission

- Public source: https://github.com/Abdallahkhale/itlegend-course-platform
- Live demonstration: https://itlegend-course-player-abdallah.abdallahkha211.chatgpt.site
- Challenge form: https://challenges.itlegend.net/frontend-hiring#submit

Before submitting, open both links in a private browser window and try one catalog-to-player journey. Provide your own name, email, phone number, and any other identity fields requested by the form. Add a CV or LinkedIn post only if you want to use the optional fields.

The implementation uses Next.js App Router and TypeScript, provides six complete mock courses, and includes the annotated player interactions. Setup, architectural choices, asset attribution, and actual validation are documented in the repository. Persistence is local to the visitor's browser; the bundled media is a playable demonstration sample.

The participant remains responsible for checking the current deadline and submitting the form. No organizer message, social post, or competition submission has been sent.
